# Politique de confidentialité

- **Dans l'app** : la page est dans Réglages → Confidentialité → Politique de confidentialité (4 langues).
  Tes informations (nom, ville, e-mail, hébergeur, date) se remplissent dans **un seul fichier** :
  `RedAlert/Settings/LegalInfo.swift` (visible dans Xcode).
- **Ces fichiers .md** servent seulement pour la version web, à publier plus tard (Apple demande une adresse web lors de la soumission sur l'App Store). Ils ne sont pas dans Xcode, c'est normal.
